# 코드 리뷰 프로젝트 프로필 (기본값)

[코드 리뷰 워크플로우](../code-review.md)가 프로젝트마다 달라지는 값을 읽는 자리입니다. 프로젝트 저장소에 `docs/profiles/code-review.md`가 있으면 그 문서가 이 기본값을 대체합니다. 프로젝트 프로필은 아래 절 제목을 그대로 쓰고, 정하지 않은 절은 기본값을 따릅니다.

## base ref

`origin/main`. 기본 브랜치가 다르면 여기서 바꿉니다.

## 리뷰 대상 디렉터리

제한 없음. 모노레포에서 특정 앱만 리뷰 대상이면 디렉터리 목록을 적습니다.

## 자동 검사 표

CI나 린터가 이미 강제해 리뷰에서 반복하지 않을 항목입니다. 기본값은 비어 있으며, 비어 있으면 모든 관점을 리뷰에서 직접 확인합니다.

| 이미 강제되는 항목 | 검사 |
|---|---|
| (없음) | |

자동 검사 보장이 없는 영역(예: CI가 없는 하위 앱)이 있으면 여기 적습니다.

## 관점별 기준 문서

관점 번호는 워크플로우의 표를 따릅니다. 문서를 지정하지 않은 관점은 워크플로우의 일반 기준만으로 판단하고, 관점 9(계측)는 문서가 없으면 "해당 없음"으로 기록합니다.

| # | 관점 | 기준 문서 |
|---|---|---|
| 1 | 코드 스타일 | (프로젝트 코딩 스타일 문서) |
| 2 | 금지 규칙 | (없음) |
| 3 | 경계 | (프로젝트 아키텍처 문서) |
| 4 | UI 품질 | (프로젝트 UI 규칙 문서) |
| 5 | 문서 동기화 | (문서 갱신 trigger를 정한 문서) |
| 8 | 보안 | (프로젝트 보안 규칙 문서) |
| 9 | 계측 | (없음) |
| 10 | 접근성 | (프로젝트 접근성 기준 문서) |
| 11 | 테스트 신뢰도 | (프로젝트 테스트 작성 기준) |

## 접근성 프로젝트 고유 항목

워크플로우의 일반 항목에 더해 확인할 프로젝트 고유 규칙입니다. 기본값은 없음입니다. 예: 공용 overlay 컨테이너를 거치지 않은 overlay, 접근성 테스트 태그 누락.

## 전체 검사 명령

사용자가 아직 실행해야 하는 검사로 리포트에 남길 명령입니다. 기본값은 없음입니다.

## 리포트 디렉터리

`.review/`. gitignore된 경로여야 합니다.

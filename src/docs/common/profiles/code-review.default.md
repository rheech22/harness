# 코드 리뷰 프로젝트 프로필 (기본값)

[코드 리뷰 워크플로우](../code-review.md)가 프로젝트마다 달라지는 값을 읽는 자리입니다. 프로젝트 저장소에 `docs/profiles/code-review.md`가 있으면 그 문서가 이 기본값을 대체합니다. 프로젝트 프로필은 아래 절 제목을 그대로 쓰고, 정하지 않은 절은 기본값을 따릅니다.

## base ref

`origin/main`. 기본 브랜치가 다르면 여기서 바꿉니다.

## 리뷰 대상 디렉터리

제한 없음. 모노레포에서 특정 앱만 리뷰 대상이면 디렉터리 목록을 적습니다.

## 자동 검사 표

CI나 린터가 이미 강제해 리뷰에서 반복하지 않을 항목입니다. 기본값은 비어 있으며, 비어 있으면 모든 축을 리뷰에서 직접 확인합니다.

| 이미 강제되는 항목 | 검사 |
|---|---|
| (없음) | |

자동 검사 보장이 없는 영역(예: CI가 없는 하위 앱)이 있으면 여기 적습니다.

## 축별 기준 문서

축 번호는 워크플로우의 표를 따릅니다. 문서를 지정하지 않은 축은 워크플로우의 일반 기준만으로 판단합니다. 문서끼리 충돌할 때의 우선순위를 정하면 여기 적습니다.

| # | 축 | 기준 문서 |
|---|---|---|
| 2 | 설계 | (프로젝트 아키텍처 문서, 코딩 스타일 문서) |
| 3 | 안전 | (프로젝트 보안 규칙 문서) |
| 4 | 검증 | (프로젝트 테스트 작성 기준) |
| 5 | 전달 | (문서 갱신 trigger를 정한 문서) |

## 프로젝트 추가 축

다섯 축에 더해 이 프로젝트에서만 검토할 축입니다. 축마다 이름, 보는 것, 기준 문서를 적습니다. 기본값은 없음입니다.

| # | 축 | 보는 것 | 기준 문서 |
|---|---|---|---|
| (없음) | | | |

예: `6 | 접근성 | 키보드 도달과 포커스 표시, 보조기술이 읽는 이름·role·상태 | docs/conventions/accessibility.md`, `7 | 계측 | 새 경로나 대체 경로가 보내야 할 이벤트 누락 | docs/contracts/analytics-events.md`.

## 전체 검사 명령

사용자가 아직 실행해야 하는 검사로 요약에 남길 명령입니다. 기본값은 없음입니다.
